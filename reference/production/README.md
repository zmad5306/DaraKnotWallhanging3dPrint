# Original solid M production reference

[Dara-Solid-M-Baseline.3mf](Dara-Solid-M-Baseline.3mf) preserves the complete original 32-plate project before integrating the flat-core and veneer M. SHA256: `d5e57cb2cf359a46a681c052a002d991044ae35f5d5810f134c701953f97d04b`.

The development generators use this immutable project for the original geometry, material presets and support settings. The root [Dara.3mf](../../Dara.3mf) is the current 36-plate veneer-M main project. Do not substitute the old solid M or its cover bands for the new matching cores and veneers.

[Dara-Part-and-Plate-Map-Solid-M.pdf](Dara-Part-and-Plate-Map-Solid-M.pdf) and the [archived readiness notes](../../working/bambu/Dara-Photo-Frame-A1-Jointed/PRINT-READINESS-SOLID-M.md) describe this historical build. Its optional old glue-practice pair is retained on plate 32. Use the separate current test project for the zero-gap samples.
